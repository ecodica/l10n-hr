Installation
============

Prerequisites:
==============
- Odoo 17.0 Community Edition
- l10n_hr_account_base

Configuration
=============

No additional configuration is needed.

Usage
=====

On outgoing invoices or refunds forms, a field for inputting invoice time is visible.
By default, time is set to the current time, and when the user changes time, `Time Of Invoicing` will also be updated.

Known issues / Roadmap
======================

The Limitation off this module is that it uses a float field to store time (widget float_time), and because of that, seconds are not supported (when time is set, seconds in `Time Of Invoicing` will be set to 0).
