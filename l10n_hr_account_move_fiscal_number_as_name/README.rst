Installation
============

Prerequisites:
==============
- Odoo 17.0 Community Edition
- l10n_hr_account_base

Configuration
=============

In Settings > Users & Companies > Companies > Open company > Croatia Settings > Enable option Use Fiscal Number As Move Name

.. image:: /l10n_hr_account_move_fiscal_number_as_name/static/description/1.png
   :width: 1000px
   :align: center

Usage
=====

When the invoice is confirmed, it will have the same number as Fiscal Number. If Fiscal Number is not set for account move, then the default sequence will be used.
If Fiscal Name is set, then it must be the same as the Name, otherwise, a validation error will be raised.
Fiscal Number field is moved into Croatia Fiscal Data (we don't need to show the same number twice on the invoice header)

Known issues / Roadmap
======================

 - Module only replaces name with l10n_hr_fiscal_number field, all Odoo's checks (for example, number gap checks) are not covered.
